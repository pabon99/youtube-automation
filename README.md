# YouTube Automation with n8n

## Project Overview

This project demonstrates a YouTube automation workflow built using n8n. The workflow automates the configured content creation process and generates a YouTube video.

## Demo Video

[Watch the workflow demonstration](https://youtu.be/RxDNOhsPKtM)

## Final Output

[Watch the generated YouTube video](https://www.youtube.com/watch?v=AyisX4BXBBs)

## Workflow File

The exported n8n workflow JSON is available in this repository.

To use it:
1. Download the JSON file.
2. Open your n8n instance.
3. Import the workflow JSON.
4. Configure the required credentials and integrations.
5. Test the workflow before activating it.

## Technologies Used

- n8n
- APIs and integrations configured in the workflow

## Project Files

- `workflow.json` — Exported n8n workflow
- `output-link.txt` — Link to the generated YouTube video
- `README.md` — Project documentation
